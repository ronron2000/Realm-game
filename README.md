# Realm Game

Mobile-friendly browser RPG prototype.

## Version 2
- Illustrated old-world world-map presentation
- Central encounter/combat scene with monster HP display
- Box-style combat/action slots and equipment panel
- Mobile action deck
- Inventory grid, crafting, trophies, and adventure log
- Rested-time recovery and rare Soulbound Time Card drops
- Virtue, Acceleration, and Double Acceleration upgrades
- Local browser save and installable PWA support

Upload `index.html`, `manifest.json`, and `sw.js` to the root of the GitHub Pages repository.
